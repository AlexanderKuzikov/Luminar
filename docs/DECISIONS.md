# Luminar — DECISIONS

<!-- Append-only. Формат фиксирован. -->

## 2026-06-15: OpenAI-compatible API, multi-provider

**Контекст:** Разные Image API имеют разное качество и цену.

**Решение:** Любой OpenAI-совместимый эндпоинт, несколько провайдеров одновременно.

**Альтернативы:** Привязка к одному провайдеру, локальные модели.

**Trade-off:** Нет гарантии консистентности между провайдерами, но гибкость.

## 2026-06-15: Concurrency=1 для батчей

**Контекст:** Image API имеют жёсткие rate limits.

**Решение:** Последовательная обработка с retry (1s/2s/4s на 429/5xx).

**Альтернативы:** Параллельная обработка с queue.

**Trade-off:** Медленнее, но надёжнее и проще.
